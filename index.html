Privacy & Security Architecture

Guaranteed Local & Private

“What Did I Miss?” was designed from the ground up for strict security in enterprise and academic settings where chat transcripts often contain confidential roadmaps, credentials, personal contact info, and internal discussions.

  • 🛡️
    Zero External Network Calls: No backend server, no cloud analytics, and no third-party APIs. You can disconnect your Wi-Fi or check browser DevTools Network tab — zero requests are made.
  • 🧠
    Zero Persistent Storage: Messages are held only in ephemeral memory (JavaScript variables) during your active browser tab session. We never write to localStorage, sessionStorage, or cookies.
  • ⚡
    Pure Rule-Based NLP: Everything is parsed using deterministic regular expressions, grammar state machines, and keyword heuristics. We do not transmit text to external LLM providers.
  • 🧼
    Untrusted Input Sanitization: All chat content is rendered exclusively through safe DOM text APIs (Node.textContent / document.createTextNode) to completely eliminate Cross-Site Scripting (XSS).
  • 🎭
    Optional On-the-Fly PII Redaction: Built-in detection masks emails and phone numbers with a single click before you copy or share summaries.

Built with vanilla HTML, CSS & JavaScript • Open-source under MIT License • Client-side security first
